# Documentation Guide

Start with the root README for setup and demo reproduction.

- `qa/FINAL_SUBMISSION.md`: final packaging, security, production checks and deployment status.
- `qa/ASK_INTELLIGENCE.md`: finite contextual evaluation and evidence limitations.
- `qa/ENTRY_SIMPLIFICATION.md`: direct-entry navigation and session migration.
- `qa/FASTING_SIMULATION.md`: clock boundaries and non-authoritative timing safety.
- `integration/AI_RUNTIME.md`: existing Ask runtime and optional model configuration.
- `safety/RELIGIOUS_SAFETY.md`: source and escalation policy.
- `review/` and `sources/`: source provenance and reviewed coverage.
- `architecture/`, `adr/`, `research/`: design rationale and research.
- `product/`: journey descriptions.
- `evaluation/`: regression fixtures/results and evaluation design.

Earlier audits and roadmaps are historical development records, not current deployment or independent religious-approval claims. The final submission report and root README take precedence for setup and delivery status. Source material and rights-gated local recordings were not discarded during packaging.
